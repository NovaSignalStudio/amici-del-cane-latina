# Amici del Cane di Latina

Proposta di sito per l'Associazione Amici del Cane di Latina ODV, preparata per GitHub Pages nell'account NovaSignalStudio.

## Pubblicazione

- Repository previsto: `NovaSignalStudio/amici-del-cane-latina`.
- GitHub Pages: **Deploy from a branch**, branch **main**, cartella **/ (root)**.
- Indirizzo previsto dopo la pubblicazione: https://novasignalstudio.github.io/amici-del-cane-latina/
- Il sito è statico e non richiede installazione, compilazione o chiavi API.
- `.nojekyll` abilita la pubblicazione diretta dei file.

## File

- `index.html`: pagina, testi e dati delle sei schede.
- `styles.css`: layout responsive e stile, con fotografia iniziale rettangolare.
- `app.js`: menu, filtri, schede e condivisione.
- `assets/`: fotografie e font locali.
- `SOURCES.md`: fonti dei contenuti e delle fotografie.
- `FONT-LICENSE.txt` e `assets/OFL.txt`: licenza del font.

## Contenuti e aggiornamenti

Le fotografie provengono dal blog dell'associazione. I dati degli annunci sono del novembre 2025: disponibilità, età e recapiti devono essere confermati con i volontari prima del lancio ufficiale. Il sito riporta già questa precisazione.

La direttiva `noindex,nofollow` resta attiva per la proposta dimostrativa. Non costituisce una protezione dell'accesso: GitHub Pages rende il sito visitabile tramite il suo indirizzo.

Le schede si aggiornano nel codice HTML. Questa versione non include un pannello di gestione o pagamenti: i contatti e il sostegno rimandano ai canali dell'associazione.

Le modifiche pubblicate sul branch `main` vengono distribuite da GitHub Pages.
